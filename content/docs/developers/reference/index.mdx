Base URL: `https://noether-api.proudmeadow-533cf0d8.germanywestcentral.azurecontainerapps.io`. Endpoints under `/v1/account`, `/v1/referral/me` and `/v1/keys` (except the challenge) need a bearer API key; everything else is public. Amounts and prices are strings of 7-decimal fixed-point integers.

## Markets

- [`GET /v1/markets/stats`](/developers/reference/markets/get-markets-stats) — Per-asset open interest (long / short / net, from the open-positions projection) and 24h traded volume (position_opened + realized position_closed / liquidated notional).
- [`GET /v1/markets`](/developers/reference/markets/get-markets) — List all supported markets with current oracle prices.
- [`GET /v1/markets/{asset}`](/developers/reference/markets/get-markets-by-asset) — Single market detail with current oracle price.
- [`GET /v1/trades`](/developers/reference/markets/get-trades) — Recent trades, newest first.
- [`GET /v1/candles`](/developers/reference/markets/get-candles) — OHLC candles for an asset, oldest-first.

## Oracle and prices

- [`GET /v1/oracle/prices`](/developers/reference/oracle/get-oracle-prices) — All supported asset prices read live from the Noeracle shim contract.
- [`GET /v1/markets/{asset}/price`](/developers/reference/oracle/get-markets-by-asset-price) — Current oracle price for a single asset.
- [`POST /v1/oracle/heartbeat`](/developers/reference/oracle/post-oracle-heartbeat) — Keeper status ingest (shared-secret header x-keeper-secret).
- [`GET /v1/oracle/health`](/developers/reference/oracle/get-oracle-health) — Per-source oracle health: on-chain price age per asset + the keeper self-report.

## Orders and transactions

- [`GET /v1/orders/open`](/developers/reference/trading/get-orders-open) — Orders placed on the current market, folded to open / executed / cancelled, newest first.
- [`POST /v1/orders/prepare`](/developers/reference/trading/post-orders-prepare) — Build an unsigned, simulated, prepared Soroban transaction for the requested trading op.
- [`POST /v1/tx/submit`](/developers/reference/trading/post-tx-submit) — Submit a signed Soroban transaction (base64 XDR) and poll until SUCCESS, FAILED, or pollTimeoutMs (default 30s).

## Positions

- [`GET /v1/positions/open`](/developers/reference/positions/get-positions-open) — Currently open positions on the market, optionally filtered by trader.
- [`GET /v1/adl/queue`](/developers/reference/positions/get-adl-queue) — Advisory auto-deleveraging queue for one asset (public): positive-pnl positions ranked by (pnl / collateral) × leverage, quintiles 1..5 (1 = first to be deleveraged if pool coverage fails).

## Account

- [`GET /v1/account/me`](/developers/reference/account/get-account-me) — Identity and tier of the authenticated API key holder.
- [`GET /v1/account/me/events`](/developers/reference/account/get-account-me-events) — Decoded contract events whose payload references the authenticated owner address.
- [`GET /v1/account/me/positions`](/developers/reference/account/get-account-me-positions) — Open positions for the authenticated owner (from the indexer positions projection), plus the owner's position events (position_opened, position_closed, position_liquidated).
- [`GET /v1/account/me/orders`](/developers/reference/account/get-account-me-orders) — Order-related events for the authenticated owner.
- [`GET /v1/account/volume`](/developers/reference/account/get-account-volume) — Trailing 14-day traded notional for a wallet (public).
- [`GET /v1/account/shortfall`](/developers/reference/account/get-account-shortfall) — Claimable shortfall for a wallet (public, L0-3): USDC the vault still owes this trader from payouts it could not cover in full, plus the global repayment reserve.

## Vaults

- [`GET /v1/vaults`](/developers/reference/vaults/get-vaults) — List all vaults the indexer knows about (newest first).
- [`GET /v1/vaults/{id}`](/developers/reference/vaults/get-vaults-by-id) — Detailed view of a single vault.
- [`GET /v1/vaults/{id}/trades`](/developers/reference/vaults/get-vaults-by-id-trades) — Leader open/close trade history for a vault, newest first.
- [`GET /v1/vaults/{id}/deposits`](/developers/reference/vaults/get-vaults-by-id-deposits) — Deposit history for a vault, newest first.
- [`GET /v1/vaults/{id}/withdraws`](/developers/reference/vaults/get-vaults-by-id-withdraws) — Withdraw history for a vault, newest first.
- [`GET /v1/vaults/{id}/fee-claims`](/developers/reference/vaults/get-vaults-by-id-fee-claims) — Leader profit-share claim history for a vault.

## Referral

- [`GET /v1/referral/lookup`](/developers/reference/referral/get-referral-lookup) — Resolve a referral code to its referrer (public).
- [`GET /v1/referral/info`](/developers/reference/referral/get-referral-info) — Look up a referrer profile by Stellar address (public).
- [`GET /v1/referral/me`](/developers/reference/referral/get-referral-me) — Returns the referral state of the authenticated owner — both their own referrer row (if any) and the binding they hold as a referee (if any).
- [`GET /v1/referral/me/trades`](/developers/reference/referral/get-referral-me-trades) — Trades the authenticated owner has earned referral fees on.
- [`GET /v1/referral/me/claims`](/developers/reference/referral/get-referral-me-claims) — Claim history for the authenticated owner as referrer.

## Leaderboard

- [`GET /v1/leaderboard`](/developers/reference/leaderboard/get-leaderboard) — Trader leaderboard from the indexer projections, ranked in SQL per deployment scope.
- [`GET /v1/leaderboard/rank`](/developers/reference/leaderboard/get-leaderboard-rank) — One trader's rank and row on the full board for a (scope, sort), looked up in the same snapshot the board pages slice, so it is always consistent with the pages and costs no extra scan.
- [`GET /v1/leaderboard/totals`](/developers/reference/leaderboard/get-leaderboard-totals) — Market wide headline totals (distinct traders, traded notional, trade count), aggregated in SQL over EVERY trader rather than the ranked page.

## API keys

- [`GET /v1/keys/beta-status`](/developers/reference/keys/get-keys-beta-status) — Public — reports whether key issuance is currently gated to a closed-beta allowlist, and optionally whether the supplied address is on it.
- [`POST /v1/keys/challenge`](/developers/reference/keys/post-keys-challenge) — Issue a one-time challenge string the wallet must sign before an API key can be created.
- [`GET /v1/keys`](/developers/reference/keys/get-keys) — List all API keys owned by the authenticated key holder.
- [`POST /v1/keys`](/developers/reference/keys/post-keys) — Exchange a signed challenge for a freshly minted API key + secret.
- [`DELETE /v1/keys/{keyId}`](/developers/reference/keys/delete-keys-by-keyId) — Revoke an API key.

## Events and health

- [`GET /v1/health`](/developers/reference/system/get-health) — Liveness + config probe.
- [`GET /v1/events`](/developers/reference/system/get-events) — Raw decoded contract events captured by the indexer.
